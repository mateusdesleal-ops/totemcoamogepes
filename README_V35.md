# V35 — Ajustes finais para o totem

Principais ajustes desta versão:
- Foto de capa da página inicial substituída por foto real do prédio, com leve melhoria de nitidez.
- Página inicial simplificada: removido o painel lateral com QR Code e atalhos.
- Hero da home centralizado e com textos posicionados na parte superior.
- Modo apresentação ajustado para manter títulos e frases no topo, com maior destaque.
- Página de vagas ajustada para evitar sobreposição/"encavalamento" dos cards no totem.
- Atualização de cache-busting para `?v=35.0`.
