# Totem Coamo/GEPES — V9

Correção definitiva dos slides institucionais do modo apresentação.

## Mudança principal
Unicoamo, Qualidade de Vida, Coamo + Saúde, FUPS, ARCAM e Programa de Estágio não usam fotografia de fundo.
A camada de fotografia e o sombreado são ocultados tanto por JavaScript quanto por CSS, e a marca do programa passa a ocupar um painel principal de destaque.

## Cache
A V9 utiliza arquivos novos `app.v9.js` e `styles.v9.css` para impedir que o navegador/Vercel reutilize a versão visual anterior.
Por isso, é obrigatório enviar também os arquivos HTML desta atualização.

## Estágio
A logo nova do Programa de Estágio continua desligada por padrão. Quando desligada, o slide usa a identificação textual "Programa de Estágio".
