# V42 — Desafio da Classificação

Novo jogo arcade para visitantes do estande.

## Como funciona
- Partida de 75 segundos.
- Itens passam por uma esteira cada vez mais rápida.
- O visitante arrasta ou toca para classificar soja, milho, trigo e impurezas.
- Pontuação por acerto, combo, precisão, vidas e resultado final.
- Não salva pontuação, nível ou progresso do visitante.
- Reinicia automaticamente após o resultado para o próximo visitante.
- Toninho e Aroldinho reagem aos acertos e erros.
- Layout adaptado para o totem vertical.

## Publicação
Substitua os arquivos do pacote mantendo-os na raiz do site. O novo arquivo `jogo-classificacao.html` também deve ser enviado.
