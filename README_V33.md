# Coamo Totem V33 — ajuste real para totem vertical

Esta versão foi feita a partir das fotos do totem físico (layout retrato).

Principais correções:
- breakpoint dedicado para telas verticais próximas de 1080×1920;
- menu superior em duas faixas, sem esmagar os links;
- home em uma coluna e nova foto de capa com a sede real da Coamo;
- vagas em uma coluna, filtros maiores e QR compacto;
- Conheça a Coamo com cards legíveis em uma coluna;
- Sorteio com vídeo 16:9 real e formulário abaixo;
- modo apresentação refeito para retrato, incluindo slides institucionais;
- Coamo Games e jogos ajustados para largura do totem;
- Missão com HUD e cena em layout vertical;
- novos arquivos versionados styles.v33.css e app.v33.js para evitar cache.
