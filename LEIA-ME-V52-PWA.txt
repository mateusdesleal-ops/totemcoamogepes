COAMO TOTEM — PWA FULLSCREEN V52

Objetivo
- Permitir instalar o site no totem Android como aplicativo/PWA.
- Abrir sem a barra de endereço e sem as abas do Chrome.
- Solicitar fullscreen no primeiro toque como fallback para navegadores Android que não respeitam o modo PWA.

INSTALAÇÃO NO TOTEM ANDROID
1. Suba todos os arquivos deste ZIP mantendo as pastas.
2. Abra o site no Chrome do totem.
3. Menu ⋮ > Instalar app. Se aparecer apenas “Adicionar à tela inicial”, use essa opção.
4. Feche a aba normal do Chrome.
5. Abra “Coamo Totem” pelo ícone criado na tela inicial.
6. A partir do ícone instalado, a aplicação solicita display fullscreen.
7. Em navegadores que ainda exibirem controles, o primeiro toque na tela tenta ativar a Fullscreen API automaticamente.

IMPORTANTE
- Abrir o endereço pela barra do Chrome continuará sendo uma aba normal. Para remover a barra, é necessário abrir pelo ícone instalado do PWA.
- Alguns firmwares Android corporativos podem manter a barra de navegação/status do sistema. Isso é uma limitação do sistema operacional; para bloquear também essas barras é necessário modo quiosque/MDM ou navegador dedicado.
- O service worker usa rede primeiro para evitar que versões antigas do site fiquem presas em cache.
