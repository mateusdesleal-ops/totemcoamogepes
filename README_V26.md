- Uma fase de imprevisto é sorteada a cada partida.
- Pontuação, consequências e resultado final.
- Toninho e Aroldinho orientam a missão.
- Novo controle no painel oculto para exibir/ocultar o jogo.

Observação: é uma simulação educativa e institucional, não um procedimento operacional oficial.
